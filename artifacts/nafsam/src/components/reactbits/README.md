# React Bits components

These components are copied from https://github.com/DavidHDev/react-bits
(`src/ts-default`, the plain-CSS variants) and are used as-is, except:

- `BlurText.tsx` imports from `framer-motion` instead of `motion/react`
  (same API, and `framer-motion` is already a dependency of this app).

Their license is in `LICENSE.md` (MIT + Commons Clause). Do not sell this
code on its own. Use it as part of the site.
